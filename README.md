🦋🦋🦋🦋🦋🦋 Tracking the Bug — A Modern Bug Tracker Based on Butterfly Model🦋🦋🦋🦋🦋
"Tracking the Bug" is a light-weight and browser-based bug tracker created as part of a unique software development approach called Butterfly Model.
The project shows how non-linear and iterative development allows one to increase security and stability compared to traditional software life-cycle approaches like Waterfall and Agile.

Repository includes:

Tracking the Bug artefact (HTML, CSS, JS)

Description of the Butterfly Model

Context of research for MSc dissertation

Architecture, Requirements, Evaluation

Introduction
Track the Bug has been designed to reflect the following key aspects of the Butterfly Model:

Iterative metamorphosis (continuous change instead of phases)

Security-by-design throughout each process step

Handling of uncertainty and failure dynamically

Role-based cooperation (Developer, Tester, Manager)
